# Web Vulnerability Lab

A self-developed vulnerable web application created for practicing OWASP Top 10 vulnerabilities and improving web application penetration testing skills.

## Features
- SQL Injection Practice
- XSS Testing
- IDOR Simulation
- Basic Authentication Testing

## Technologies Used
- Python
- Flask
- HTML

## Objectives
- Practice manual penetration testing
- Understand common web vulnerabilities
- Learn secure coding concepts
- Simulate real-world web security testing

## Installation

```bash
pip install -r requirements.txt
python app.py
```

## Disclaimer
This project is developed strictly for educational and authorized security testing purposes.
